HTML Structure

GlobeTrek Travel Tour Listing HTML Template

GlobeTrek is a modern and professionally designed Travel Tour Listing HTML Template, crafted for travel agencies, tour operators, and booking platforms. With a clean layout, responsive design, and user-friendly interface, GlobeTrek makes it easy to showcase destinations, tour packages, and travel experiences in an engaging way. Built with the latest HTML5, CSS3, and JavaScript technologies, this template ensures fast performance, smooth animations, and seamless compatibility across all devices and browsers. It includes well-structured pages for tour listings, destination details, booking forms, blogs, and more — making it a perfect solution for creating a stunning travel website.

Example Edit Template

1. Example of how to edit the logo template


You change the logo image in the folder of project "Images" of your logo images, the same name as the original (logo.png)
Project Amerce:-> images -> logo.png

2. Example of how to edit the "product style" template

Style list: If you want to use style listuse the sample below

    <div class="card-product list-layout">

    	</div>
    </div>
